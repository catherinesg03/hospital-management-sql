# Hospital Management Database Analysis using MySQL

## Project Overview
A relational database project developed using MySQL to manage doctor and patient records and perform SQL-based data analysis.

## Database Tables
- DoctorTable
- PatientTable

## SQL Concepts Covered
- Database and Table Creation
- Primary Keys and Foreign Keys
- INSERT, UPDATE and ALTER
- SELECT, WHERE and DISTINCT
- INNER JOIN and LEFT JOIN
- GROUP BY and HAVING
- Aggregate Functions
- Subqueries
- ORDER BY and LIMIT

## Project Analysis
Performed 35+ SQL queries to analyse doctor salaries, specializations, patient demographics, disease distribution, and doctor-patient relationships.

## Tools Used
- MySQL
- MySQL Workbench
